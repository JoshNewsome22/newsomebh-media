# newsomebh-media

Published videos and images for Newsome Behavioral Health.

This repository is public on purpose: social platforms (YouTube, Instagram, Facebook) download files from these
links when posting. Only finished, approved files that are already meant for the public go here.

**Never add:** scripts, research, client or student information, workstation forms, or anything not yet approved.

| Folder | Contents |
|---|---|
| `videos/<episode>/` | Finished videos, Shorts and thumbnails |
| `images/social/` | Social post images |

Videos use AI narration and AI-simulated scenes; no real clients, students or families are shown.
General information only, not medical, clinical or educational advice about any individual.
